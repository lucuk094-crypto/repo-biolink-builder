1️⃣ INSTALL NODE.JS (Jika belum punya)

   - Browser otomatis buka
   
   ✅ Aplikasi berjalan di: http://localhost:3000

🎯 CARA DEPLOY KE VERCEL (GRATIS!):
═══════════════════════════════════════════════════════════════

OPSI 1: Via Vercel CLI (Termudah)
   1. Install Vercel CLI:
      npm i -g vercel
   
   2. Deploy:
      vercel
   
   3. Ikuti instruksi di layar
   4. Selesai! Link langsung jadi


OPSI 2: Via Vercel Dashboard
   1. Push code ke GitHub
   2. Buka vercel.com
   3. Import repository
   4. Click Deploy
   5. Tunggu 1-2 menit
   6. Selesai!

❓ TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════

❌ Error: "node is not recognized"
   → Node.js belum terinstall
   → Download dari nodejs.org

❌ Error: "Port 3000 already in use"
   → Port sudah dipakai aplikasi lain
   → Tutup aplikasi yang pakai port 3000
   → Atau gunakan port lain: npm run dev -- -p 3001

❌ Error: "Module not found"
   → Hapus folder node_modules
   → Jalankan: npm install

❌ Preview tidak update
   → Refresh browser (F5)
   → Clear cache (Ctrl+Shift+Delete)

❌ Export tidak jalan
   → Allow pop-ups di browser
   → Cek folder Downloads
