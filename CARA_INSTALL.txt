LANGKAH 1: INSTALL NODE.JS (Jika belum punya)
═══════════════════════════════════════════════════════════════════

1. Buka browser, kunjungi: https://nodejs.org/

2. Download versi LTS (Long Term Support)
   - Pilih yang ada tulisan "Recommended for Most Users"
   - File size sekitar 30-50 MB

3. Install Node.js:
   - Double-click file yang sudah didownload
   - Klik Next, Next, Next... sampai selesai
   - Tunggu proses instalasi (2-3 menit)
   - Klik Finish

4. Verifikasi instalasi:
   - Buka Command Prompt (tekan Win+R, ketik "cmd", Enter)
   - Ketik: node -v
   - Harus muncul versi seperti: v18.17.0 atau v20.x.x
   - Ketik: npm -v
   - Harus muncul versi seperti: 9.x.x atau 10.x.x

✅ Jika muncul versi, Node.js sudah terinstall!
❌ Jika muncul error, restart komputer dan coba lagi

═══════════════════════════════════════════════════════════════════
LANGKAH 2 (ALTERNATIF): INSTALL MANUAL
═══════════════════════════════════════════════════════════════════

Jika cara otomatis tidak jalan, ikuti cara manual:

1. Buka Command Prompt di folder ini:
   - Shift + Right-click di folder biolink-builder
   - Pilih "Open PowerShell window here" atau "Open command window here"

2. Install dependencies:
   Ketik: npm install
   Tekan Enter
   Tunggu 1-3 menit (download packages dari internet)

3. Jalankan aplikasi:
   Ketik: npm run dev
   Tekan Enter
   Tunggu sampai muncul: "ready started server..."

4. Buka browser:
   Ketik di address bar: http://localhost:3000
   Tekan Enter

5. TAB BUTTONS:
   ✅ Pilih bentuk button: Rounded/Square/Circle
   ✅ Pilih efek: None/Glow/3D
   ✅ Pilih hover animation: Slide/Bounce/Scale
   ✅ Pilih posisi icon: Left/Right/None

6. TAB LINKS:
   ✅ Klik "Add Link" untuk tambah link baru
   ✅ Isi Title (nama button)
   ✅ Isi URL (link tujuan)
   ✅ Pilih emoji icon atau upload gambar
   ✅ Gunakan tombol ⬆️⬇️ untuk reorder
   ✅ Gunakan 👁️ untuk show/hide
   ✅ Gunakan 🗑️ untuk delete

7. EXPORT:
   ✅ Klik tombol "Export HTML" di panel kanan
   ✅ File HTML akan terdownload
   ✅ Buka file HTML untuk test
   ✅ Siap untuk di-deploy!

LANGKAH 4: DEPLOY KE VERCEL (GRATIS!)
═══════════════════════════════════════════════════════════════════

CARA 1: Via Vercel CLI (Termudah)

1. Install Vercel CLI:
   Buka Command Prompt, ketik:
   npm i -g vercel

2. Login ke Vercel:
   Ketik: vercel login
   Pilih metode login (GitHub/Email)

3. Deploy:
   Ketik: vercel
   Ikuti instruksi di layar
   Tunggu 1-2 menit
   Link live akan muncul!

CARA 2: Via Vercel Dashboard

1. Push code ke GitHub:
   - Buat repository baru di GitHub
   - Upload semua file project

2. Buka vercel.com dan login

3. Klik "New Project"

4. Import repository dari GitHub

5. Klik "Deploy"

6. Tunggu 1-2 menit

7. Selesai! Link live akan muncul

TROUBLESHOOTING (JIKA ADA MASALAH):
═══════════════════════════════════════════════════════════════════

❌ MASALAH: "node is not recognized"
✅ SOLUSI: Node.js belum terinstall atau belum di PATH
   - Install Node.js dari nodejs.org
   - Restart Command Prompt
   - Restart komputer jika perlu

❌ MASALAH: "Port 3000 already in use"
✅ SOLUSI: Port 3000 sudah dipakai aplikasi lain
   - Tutup aplikasi yang pakai port 3000
   - Atau gunakan port lain: npm run dev -- -p 3001

❌ MASALAH: "Module not found"
✅ SOLUSI: Dependencies belum terinstall
   - Hapus folder node_modules
   - Jalankan: npm install

❌ MASALAH: "npm install" sangat lambat
✅ SOLUSI: Koneksi internet lambat
   - Gunakan koneksi internet yang lebih cepat
   - Atau tunggu sampai selesai (bisa 5-10 menit)

❌ MASALAH: Preview tidak update
✅ SOLUSI: Browser cache
   - Refresh browser (tekan F5)
   - Atau hard refresh (Ctrl+Shift+R)

❌ MASALAH: Export HTML tidak jalan
✅ SOLUSI: Pop-up diblock
   - Allow pop-ups di browser
   - Cek folder Downloads

❌ MASALAH: Gambar tidak muncul setelah export
✅ SOLUSI: Gambar tidak ter-embed
   - Gambar sudah otomatis ter-embed sebagai base64
   - Jika masih tidak muncul, cek console browser (F12)
