# 📖 Usage Guide

## Getting Started

### 1. Profile Setup

**Step 1: Upload Profile Image**
- Click "Upload Image" button
- Select an image from your device
- Recommended: Square image, at least 400x400px

**Step 2: Set Profile Name**
- Enter your name or brand name
- Keep it short and memorable

**Step 3: Write Bio**
- Add a brief description
- Maximum 2-3 lines recommended
- Tell visitors what you do

**Step 4: Choose Profile Frame**
- **Circle**: Classic, friendly look
- **Square**: Modern, professional
- **Hexagon**: Unique, creative

**Step 5: Select Profile Border**
- **None**: Clean, minimal
- **Neon**: Glowing effect
- **Gradient**: Colorful, animated
- **Animated**: Neon + Gradient combined

**Step 6: Pick Font**
- Choose from 20+ Google Fonts
- Preview updates in real-time
- Match font to your brand style

### 6. Managing Links

#### Add New Link
1. Click "Add Link" button
2. Link editor appears
3. Fill in details
4. Click outside to collapse

#### Edit Link
1. Click on link to expand
2. Update fields:
   - **Title**: Button text
   - **URL**: Destination link
   - **Icon**: Emoji or text (max 4 chars)
   - **Custom Icon**: Upload image (optional)

#### Reorder Links
- Use ⬆️ and ⬇️ buttons
- Move links up or down
- Order reflects in preview

#### Show/Hide Links
- Click 👁️ icon to toggle
- Green = visible
- Gray = hidden
- Hidden links don't appear in export

#### Delete Links
- Click 🗑️ trash icon
- Link removed immediately
- Cannot be undone

### 7. Export & Deploy

#### Export HTML
1. Click "Export HTML" button
2. Single HTML file downloads
3. No dependencies needed
4. Ready to deploy anywhere

#### What's Included
- ✅ All styles inline
- ✅ Google Fonts linked
- ✅ Animations embedded
- ✅ Fully responsive
- ✅ Works offline

#### Deploy Options

**Option 1: Vercel**
```bash
vercel
```

**Option 2: Netlify**
```bash
netlify deploy
```

**Option 3: GitHub Pages**
- Upload HTML to repository
- Enable GitHub Pages
- Access via username.github.io

**Option 4: Any Web Host**
- Upload HTML file
- Access via your domain
- Works on any server

## Tips & Best Practices

### Profile Image
- ✅ Use high-quality images
- ✅ Square aspect ratio
- ✅ Minimum 400x400px
- ✅ Face centered
- ❌ Avoid blurry images
- ❌ Don't use logos (unless brand page)

### Profile Name
- ✅ Keep it short (2-3 words)
- ✅ Use your real name or brand
- ✅ Capitalize properly
- ❌ Avoid all caps
- ❌ Don't use special characters

### Profile Bio
- ✅ 1-2 sentences max
- ✅ Clear and concise
- ✅ Include what you do
- ❌ Avoid long paragraphs
- ❌ Don't use jargon

### Links
- ✅ Prioritize important links first
- ✅ Use clear, action-oriented titles
- ✅ Test all URLs before export
- ✅ Use relevant icons/emojis
- ❌ Don't add too many links (5-10 ideal)
- ❌ Avoid generic titles like "Click here"

### Design
- ✅ Choose theme that matches brand
- ✅ Keep it readable
- ✅ Test on mobile devices
- ✅ Use animations sparingly
- ❌ Don't mix too many styles
- ❌ Avoid low contrast colors

### Performance
- ✅ Optimize images before upload
- ✅ Use WebP format when possible
- ✅ Keep animations subtle
- ✅ Test loading speed
- ❌ Don't use huge images
- ❌ Avoid too many animations

## Troubleshooting

### Image Won't Upload
- Check file size (max 5MB recommended)
- Use JPG, PNG, or WebP format
- Try different browser

### Preview Not Updating
- Refresh the page
- Clear browser cache
- Check browser console for errors

### Export Not Working
- Allow pop-ups in browser
- Check download folder
- Try different browser

### Links Not Clickable
- Ensure URL starts with http:// or https://
- Test URL in new tab first
- Check for typos

## FAQ

**Q: Can I save my work?**
A: Currently, data is stored in browser. Export HTML to save permanently.

**Q: Can I edit exported HTML?**
A: Yes! Open in any text editor and modify as needed.

**Q: Is it mobile responsive?**
A: Yes! All themes are fully responsive.

**Q: Can I use custom CSS?**
A: Yes, in exported HTML. Add styles in `<style>` tag.

**Q: How many links can I add?**
A: Unlimited! But 5-10 is recommended for best UX.

**Q: Can I use custom fonts?**
A: Yes! Edit exported HTML and add Google Fonts link.

**Q: Is it free?**
A: Yes! Completely free and open source.

**Q: Can I use for commercial?**
A: Yes! MIT license allows commercial use.
