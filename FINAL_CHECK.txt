═══════════════════════════════════════════════════════════════════

   3. Ikuti instruksi
   4. Selesai!

OPSI 2: Via Vercel Dashboard
   1. Push ke GitHub
   2. Buka vercel.com
   3. Import repository
   4. Click Deploy
   5. Selesai!
